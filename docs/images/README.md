# Images

Place real photos and media here. The docs reference the following files;
drop in your assets using these names (or update the references in the docs).

| File | Used by | Description |
|------|---------|-------------|
| `dongle-photo.png` | `HARDWARE.md` | Product photo of the dongle (front view) |
| `install-photo.png` | `HARDWARE.md` | Photo of the dongle plugged into a meter's P1 port |

Notes:

- Prefer PNG or JPG; keep images reasonably sized (e.g. ≤ 1024 px wide).
- `connection-diagram.svg` is a generated diagram (no photo needed).
- A short install video can be linked instead of embedded — GitHub does not
  render embedded video in Markdown. Use the YouTube link in `USER_MANUAL.md`.
